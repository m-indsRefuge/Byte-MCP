# Byte-MCP V1.1 Local Validation

## Purpose

Establish repeatable evidence that the hardened V1.1 server preserves the V1 read-only contract while enforcing its runtime and audit boundaries.

## Preconditions

- PowerShell 7 or later
- Python 3.12 virtual environment at `.venv`
- `config/roots.local.json` present
- Byte-MCP branch `byte/v1.1-runtime-hardening` checked out
- test file `byte-mcp-v1-test-note.txt` present in the approved `downloads` root for the full search/fetch gate

## Gate A — repository validation

```powershell
.\scripts\Check.ps1
```

Required results:

- Python compilation passes
- Ruff passes
- Pytest passes
- dependency consistency check passes

## Gate B — server startup

```powershell
.\scripts\Run-Server.ps1
```

Required result:

- server remains running at `http://127.0.0.1:8000/mcp`

## Gate C — protocol discovery

In a second PowerShell terminal:

```powershell
.\scripts\Run-Smoke-Test.ps1
```

Required result:

```text
classification: successful_validation
```

The evidence must list:

- `list_roots`
- `list_directory`
- `search`
- `fetch`

## Gate D — search/fetch flow

```powershell
.\scripts\Run-Smoke-Test.ps1 `
    -Root downloads `
    -Query "byte-mcp-v1-test-note" `
    -ExpectName "byte-mcp-v1-test-note.txt"
```

Required results:

- search returns the expected file
- fetch returns a 64-character SHA-256
- extractor is `text`
- content is not truncated

## Gate E — denial audit

Run the unit tests, then inspect the audit ledger:

```powershell
Get-Content .\data\audit.jsonl -Tail 20
```

Required properties:

- allowed operations have `outcome` set to `allowed`
- rejected operations have `outcome` set to `denied`
- raw search terms are absent
- raw opaque references are absent
- fetched file contents are absent

## Gate F — network boundary

From a clean terminal, this command must fail before server startup:

```powershell
$env:BYTE_MCP_HOST = "0.0.0.0"
.\scripts\Run-Server.ps1
```

Remove the test environment variable afterward:

```powershell
Remove-Item Env:BYTE_MCP_HOST
```

Required result:

```text
BYTE_MCP_HOST must remain loopback-only in V1
```

## Acceptance classification

V1.1 may be accepted only when Gates A through F pass and the Git working tree is clean.

```text
BYTE-MCP V1.1 LOCAL RUNTIME HARDENING
Classification: successful_validation
```
